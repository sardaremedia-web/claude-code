# Видео: «Неге пакеттің бағасы өзгермейді?»

Формат: 1080×1920, ~39 сек, Sartai Voice (eleven_v4, 1.05×), инфографика (v4 торы: 90/40, тақырып 150–330, мазмұн 420–1560, субтитр 1650, ≤3 сөз).

Дубляж мәтіні:
> Неге Сардар Медиа пакеттерінің бағасы өзгермейді? Жауабы қарапайым. Пакет дегеніміз бірнеше маманнан құралған дайын команда. Оның бағасы сол мамандарды біріктіріп, алдын ала есептелген. Сондықтан пакетке жеңілдік қарастырылмаған. Ал маманды жеке алсаңыз, жеңілдік сұрауға болады. Жеке бағалар мынадай. Фотограф, кью-ар жүйесімен бірге, алпыс мың теңге. Мобилограф, қырық бес мың теңге. Видеограф, сексен мың теңге. Оператор, сексен мың теңге. Бір ғана маман керек болса, жазыңыз, бағасын бірге келісеміз. Ал толық команда керек болса, пакетті таңдаңыз.

Сахналар: баға тағы + құлып → «қарапайым» (? → !) → 4 маман ұшып келіп «ПАКЕТ» рамкасына бірігеді → мамандар = құлыптаулы баға → «−%» белгісі құлыпқа соғылып кері ұшады → пакет ажырап, әр маманға «−%» жабысады → жеке бағалар (60 000 / 45 000 / 80 000 / 80 000, «−% келісуге болады») → «1 маман: бірге келісеміз» / «Толық команда: пакетті таңдаңыз» → лого.

Ескерту: пакет пен жеке бағалардың қосындысы салыстырылмайды (ROYAL, BASIC үшін қосынды пакет бағасына тең).
